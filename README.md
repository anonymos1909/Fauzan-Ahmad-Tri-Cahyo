# Fauzan-Ahmad-Tri-Cahyo
UTS PEMROGRAMAN WEB 1

PROJECT WEBSITE STATIS - RUANG HIJAU

Isi folder:
- index.html       : halaman utama / profil singkat
- profil.html      : halaman profil lengkap, program, dan tabel kegiatan
- style.css        : semua aturan styling CSS
- assets/          : ilustrasi SVG untuk website
- screenshots/     : tangkapan layar halaman website
- naskah-demo.txt  : panduan penjelasan video demonstrasi 5-10 menit

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder ruang-hijau.
3. Klik dua kali index.html atau buka dengan browser.
4. Gunakan menu Beranda dan Profil & Program untuk berpindah halaman.

Hosting gratis dengan GitHub Pages:
1. Login ke GitHub dan buat repository baru, misalnya ruang-hijau.
2. Upload semua file dan folder di dalam folder ruang-hijau ke repository.
3. Buka Settings > Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder /(root), lalu Save.
6. Tunggu proses selesai. URL website akan muncul pada halaman Pages.

Catatan: hosting online perlu dilakukan dari akun GitHub milik sendiri. Website ini sudah statis dan tidak memerlukan database atau backend.
